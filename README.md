## Roadmap at a glance

1. **Set up the learning workflow:** GitHub repository, Markdown notes, small commits, and a weekly review.
2. **Learn programming with Python:** variables, types, conditions, loops, functions, collections, files, exceptions, modules, and object-oriented programming.
3. **Build the web-development track:** semantic HTML, CSS layout and responsive design, JavaScript fundamentals, and browser tools.
4. **Study computer science foundations:** data structures, algorithms, complexity analysis, operating systems, networking, and databases.
5. **Build full applications:** APIs, backend logic, database integration, authentication concepts, and testing.
6. **Improve software quality:** debugging, automated tests, clean code, documentation, and basic design principles.
7. **Deploy and maintain projects:** GitHub Actions, environment configuration, deployment, logging, and security basics.

The phases are sequential at a high level, but practice and review will continue throughout the journey. I will not study every language or specialization at once.

## How I will use my books

- **Beginning Programming All-in-One Desk Reference For Dummies:** Use selectively for broad programming concepts, data structures, and algorithms. Treat its older examples as historical/reference material.
- **Python learning collection:** Use *Python Crash Course* as the main hands-on beginner resource; consult *Learning Python* when I need deeper explanations. Keep *Effective Python*, *Python Cookbook*, and *Fluent Python* for later practice and reference.
- **Coding All-in-One For Dummies:** Use the HTML/CSS, JavaScript, and web-application sections while building my website. Its data-analysis and machine-learning material is a later optional track.
- **Advanced Java** and **Apache Maven Cookbook:** Keep for a future Java track, after learning core Java. They are not part of my immediate study priority.

Reference repositories:

Older books can teach durable concepts, but I will check current official documentation for tools, libraries, and version-specific instructions. I will use materials lawfully and will not redistribute copyrighted files without permission.

## My weekly learning loop

1. Choose one small concept or goal.
2. Study it and write a short explanation in my own words.
3. Write code without copying the full solution.
4. Change the example and debug at least one issue when possible.
5. Commit working progress to GitHub.
6. Record what worked, what was difficult, and the next step.

## Definition of done

I will mark a topic as complete only when I can explain the main idea, write or modify a working example, debug common mistakes, and identify what I still do not understand. Reading a chapter alone is not completion.
